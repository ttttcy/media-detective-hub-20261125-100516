# 智媒侦察局

**Media Detective Hub (MDH)** · 看见细节，辨明真相。

完整的四模块互动训练网站，包含代码、Logo、六张照片、全部视频和解析截图。原生 HTML / CSS / JavaScript，无安装依赖或构建步骤。

## 四个模块

| 模块 | 内容 | 评分 |
| --- | --- | --- |
| N1 新闻视频观察 | 初始判断、眨眼、手部纹理、语速与节奏、复判 | 五项各20，共100分 |
| N2 照片识别 | 六图多选、取消、放大及答案解析 | 四张正确选项各25，共100分 |
| N3 新视频判断 | 看完视频后二选一，提交后展示截图解析 | 100分 |
| N4 故事视频观察 | 完整视频判断、四段细节判断与揭示 | 五项各20，共100分 |

最终按实际作答生成四点成绩曲线、分项得分和初判/复判对照；支持打印、HTML和JSON导出。所有分数仅在训练结束后展示。多选误选不扣分，漏选不得分；答案提交后锁定。

## GitHub Pages 发布

仓库 Settings → Pages → Build and deployment：选择 Deploy from a branch，分支 main，目录 /(root)，保存。网站文件就在仓库根目录，.nojekyll 禁用不需要的模板处理。

## 本地运行

在本目录运行 `python3 -m http.server 4173`，浏览器打开 http://127.0.0.1:4173 。使用HTTP访问，勿直接双击index.html运行ES modules。

## 文件

- index.html、app.js、data.js、scoring.js、styles.css：完整界面、题目、交互和计分源代码。
- assets/：机构Logo。
- media/：原声训练视频、六张照片、视频封面及解析截图。
- .nojekyll：GitHub Pages静态发布设置。

素材用于媒介素养训练，真伪答案按提供者标签设置。答题记录仅在当前页面内存中，刷新或关闭会清空，请在结束后导出报告。网站没有账号或后台数据库。
