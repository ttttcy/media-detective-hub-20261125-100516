# 智媒侦察局 · Media Detective Hub

四模块影像识别互动训练网页，支持电脑和手机。

在线使用：https://ttttcy.github.io/media-detective-hub-20261125-100516/

## v1.8.1

- N1：新闻视频初判、眨眼／手部／语速观察及复判。
- N2：六张照片的选择、放大与解析。
- N3：新视频真假判断及截图解析。
- N4：网传桥梁视频、人员撤退／玻璃破裂／人物重心／跑步动作四段观察，最后观看事件解读报道（不设题）。
- 首页与目录可自由进入各模块；“上一步”保留答案及草稿。
- 所有视频播放结束停留原页，点击按钮后继续。
- 讲话视频在播放按钮上方显示简洁同步字幕，附WebVTT字幕轨。两处听辨不清的名称已标注。
- 最后按实际作答生成四模块成绩曲线，支持HTML/JSON导出和打印。

每模块满分100，总分400。照片多选正确选中得分，误选不扣、漏选不计；报告另列误选记录。训练分数不构成正式能力测评。

纯HTML/CSS/JavaScript，无构建依赖。根目录部署到静态HTTP服务即可使用。记录只在当前页面内存中，刷新或关闭会清空。

素材仅用于媒介素养训练。保留用户提供的图像、视频和原声；题目标签由提供者给定，字幕由原声转写整理。标称桥梁倒塌的网传视频不应视为真实事故证据。
